# 创建页面

## 目录结构

```bash
src/views/user-module/       # 模块名称（kebab-case）
├── user-management/         # 页面名称（kebab-case）
│   ├── components/          # 页面私有组件
│   │   ├── user-filter.ts   # 类型定义
│   │   └── user-filter.vue
│   ├── styles/              # 样式
│   │   ├── index.scss
│   │   └── user-filter.scss
│   ├── index.vue            # 页面主文件（大驼峰命名）
│   ├── types.ts             # 类型定义
│   └── utils.ts             # 页面工具函数
```
